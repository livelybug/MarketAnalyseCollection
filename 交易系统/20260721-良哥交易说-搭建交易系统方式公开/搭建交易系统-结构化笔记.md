# 搭建交易系统的方式（结构化笔记）

> 来源：`video.ai-zh.srt`（良哥交易说，2026-07-21，约30分钟）
> 主讲人自述做了8年交易。本文只整理其观点结构与原话要点，不添加外部内容。

## 总览：交易系统七要素

| # | 要素 | 一句话核心 |
|---|------|-----------|
| 1 | 认知 | 先想明白挣什么钱、对手盘是谁、市场本质 |
| 2 | 技术 | 只为进出场提供依据，本质是"应对" |
| 3 | 订单管理 | 新手零管理，写好计划设好止盈止损就不盯盘 |
| 4 | 仓位管理 | 核心是资产配置，用闲钱，按风险承受力开仓 |
| 5 | 心态 | 心态就是钱；把心思放在执行上，不放在钱上 |
| 6 | 做数据（回测） | 最重要。按自己的规则一笔一笔测300~500笔 |
| 7 | 复盘 | 攒数据、反思心态、适当优化、监控策略失效 |

搭建流程是一个循环，不是一条直线：

```
 选定标的/周期/规则
        │
        ▼
 ┌─→ 做数据（历史回测 300~500笔）
 │        │
 │        ▼
 │   分析数据（盈利、胜率、盈亏比、最大回撤/连亏）
 │   分析适配（时间、感觉、频率、风险）
 │        │
 │        ▼
 │   小资金实盘（最小可承受资金）
 │        │
 │   执行得了？──否──→ 找问题（风险偏好/心态/执行力/
 │        │            时间不匹配/技术问题）──→ 改策略 ──┐
 │       是                                          │
 │        ▼                                          │
 │   正常做 + 每周复盘 ──→ 适当优化 / 发现失效则调整 ──┘
 └───────────────────────────────────────────────────
 （回测 → 分析 → 小实盘 往复，直到能执行为止）
```

## 一、认知（第一关键，先于一切技术）

**核心论点：认知不够，学什么技术都没戏。** 上来先学的不是技术，是想明白四个问题。

### 1.1 你要挣什么样的钱？

- 这个问题取决于你的**时间**。
- 时间充足（全职、不上班）→ 高频、日内都可以做。
- 上班、看盘时间很少 → 放弃高频，做波段、趋势或价值投资。
- 不要看别人挣钱就去学——那个钱不属于你（"我知道银行有钱，也不能偷不能抢"）。
- 个人建议：**时间级别稍微大一些**。周期太小特别容易上头。
- 由这一点决定你的**交易周期**（指时间周期）。

### 1.2 你为什么能挣这个钱？——对手盘是谁

想不明白挣的是谁的钱、亏的是给谁，就玩不好这个游戏。市场组成部分：

| 对手盘 | 特点 |
|--------|------|
| 高频交易公司 | 电脑端、EA、AI；提供流动性，一秒成百上千次交易（国内少些，股票/外盘多） |
| 银行端 | 职业操盘团队 |
| 资本公司 | 国内国际正规资本公司，专业操盘团队 |
| 超级个体 | 游资等，资金量极大的个人 |

- 以上四类统称**大资金方**：专业度特别强、容易形成共识、有完善的策略/方式/仓位/风控。
- 个人做高频，对手盘就是高频公司——"跟电脑玩，人脑再牛也干不过电脑"，不合理。
- **我们属于散户**：一头热血冲进去，什么都不懂，没有风控意识，资金量小，对行情走势起不到决定性作用，只是参与。

### 1.3 盘面设计的是人性，不是技术

- 所谓技术，更多是让你去**反人性**——但反人性很难。
- 交易中最大的三个人性阻碍：**贪婪、恐惧、急躁**。

## 二、技术

### 2.1 技术的核心作用

- 技术的核心就是**为进出场提供合理的依据**，没有别的。

### 2.2 完整交易技术的五个要素

| # | 要素 | 说明 |
|---|------|------|
| 1 | 方向 | 打开任何图表、任何品种，先知道干多还是干空 |
| 2 | 位置 | 方向对了要找好位置。行情往上走不能闭眼追多——万一深度回调受不了 |
| 3 | 开仓 | 左侧或右侧都行，没那么玄乎，把开仓规则定好 |
| 4 | 止损 | 规则明确 |
| 5 | 止盈 | 规则明确 |

学技术，学的就是这五件事。

### 2.3 三个前置问题（学技术前先想清楚）

| 问题 | 主讲人的答案 |
|------|-------------|
| 市场是否完全随机？ | **不是完全随机** |
| 市场有没有一定的确定性？ | **在特定情况下、特定时间节点上有一定确定性**，但有前提条件 |
| 交易技术是否真的有用？ | **有用，但必须匹配前两点**：在特定条件下、特定时间节点内有用 |

- 学技术的目的，就是**寻找这个"特定性"**——在这个特定性下，胜率在一定程度上大于50%，抓住这一瞬间进去，拿到想要的钱。

### 2.4 技术的本质是"应对"

无论什么样的技术，基础的本质就是**应对**。一定要想清楚这一点。

### 2.5 好的开仓位会提供反手的机会

- 例：区间震荡，支撑位做多、阻力位做空。为什么？
  1. 这个位置容易反转；
  2. 破位了止损非常明确，甚至可以反向接着做。
- 记住：**好的开仓位大概率会给到反手机会**。中间随手开的位置（不做在关键位上）没有这个优势——"以前我也这样，现在觉得可笑"。

## 三、订单管理（新手 vs 老手）

| | 新手 | 老手 |
|---|------|------|
| 建议方式 | **不要有任何管理** | 有减仓、保本、二次加仓、滚动仓位等动作 |
| 做法 | 交易前写明白交易计划：出现什么条件、什么情况，12345列出来；出现了就按计划干，没出现就不干；进场后设好止损止盈就完事 | 高点附近减仓、回调加仓，主要做波段行情（上涨回调上涨回调） |
| 盯盘 | **不要盯盘** | 也很少盯盘 |
| 原因/条件 | 盯盘是内耗，是交易中最大的对手。只要盯盘，总想去管单子，有这个心理就没戏。只要逻辑规则正确、不盯盘，一般人结果都不会特别差 | 需要把握市场节奏，需要大量实操经验，新手学不来 |

> 核心一句话：新手按计划进场、设好止损止盈后就不要再做任何管理，去干别的。

## 四、仓位管理

先否定一个流行说法："每单控制2%或5%"——那不是核心。仓位管理的核心是以下四点。

### 4.1 资产配置（重中之重）

- 打牌类比：有1万块，打一场最大输赢500的牌，心态老好了；兜里就500块，去玩一场输赢能到1万的牌，心态必崩。
- 结论：**用闲钱做交易**。这个钱亏了你能接受，才可能赚；亏了接受不了，根本赚不到钱。
- 大多数来做交易的是没钱的普通人，往往更难赚钱——因为**急**：就1万本金还想着一个月翻十倍。
- 网上喊单、带单、制造焦虑、展示翻倍的，卖的都是"以小博大"。以小博大成立吗？**成立，但需要运气和机会配合**。啥也不懂叮咣就是干，结果自己琢磨。

### 4.2 反向推导爆仓

- 以1万账号为例，问自己：亏5%时什么状态？亏10%呢？亏20%呢？
- 一笔单子止损要超过20%，到那时你还能不能下手止损？一定要想清楚。
- **爆仓永远是因为一笔订单**：这一单没做好，导致重仓、逆势加仓、不带止损。
- 反证：如果每单止损只亏3%~5%，要连亏20~30次才会爆仓——现实中几乎没有人真的连亏20次（闭眼瞎蒙都很难连亏20次）。所以按小止损做，爆不了仓。

### 4.3 按个人风险承受能力开仓

- 想明白第4.2点里自己亏多少会出问题，就知道自己的**风险偏好**了，再反推仓位怎么控。
- 个人做的检验标准：**这个单子开进去，不影响你吃饭、喝水、睡觉，就OK了**。设好止损止盈就不管，该干嘛干嘛去。心态平和，就是仓位合适。

### 4.4 推算胜率，按胜率优化仓位

- 具体胜率60%还是50%还是40%、盈亏比多少，都不重要；重要的是**根据过往数据推算连亏**。
- 常见错误算法：连亏概率50%→25%→12.5%一路推下去，觉得连亏很难。**不是这么算的**——每一笔都是独立个体，每次都可能亏。
- 最怕的就是连亏：连亏一多，仓位扛不住、心态扛不住、人性扛不住，整个人就崩了。有人崩在3次，有人崩在5次，但必须关注这个问题。
- 不接受亏钱、不明白自己是怎么亏的，就根本赚不到钱。

## 五、心态

- 前提：假设技术没问题、仓位没问题，那么心态自然就好——**因为心态说白了就是钱**。不用盯着钱，心态就好。
- 做法上：**把心思放在执行上，不放在钱上**。每笔交易问三个问题：
  1. 是否符合我的开仓逻辑？
  2. 是否符合规则内的盈亏比？
  3. 是否是按正确的方式做的？
- 符合规则：赚了亏了都接受。
- 不符合规则：赚了亏了都要告诉自己——这么做是不对的。
- 主讲人承认：这一关挺难过。交易看起来不用求人、不用资源、不用本钱，在家动动手指点点鼠标就赚钱——哪那么容易。

## 六、做数据（回测）——最重要的一步

> 对来学的人反复强调的一句话："一定要去做数据，做数据，做数据。"

### 6.1 回测怎么做

- 数据做的其实就是**回测**：按照你自己的交易方式，对历史行情一笔一笔地做。
- 前提：已选定交易标的（金银油、期货品种、其他都行）、选定周期、定好进出场规则。
- **必须一笔一笔去测**，至少 **300~500笔以上**。
- 主讲人自己测当前这套策略用了四个月，用掉一厚摞A4纸。

### 6.2 数据分析：四个指标

| # | 指标 | 看什么 |
|---|------|--------|
| 1 | 整体盈利能力 | 能否符合预期。别指望盈利1000倍，也别一年只赚5%——都太极端。找一个自己能接受的点 |
| 2 | 整体胜率 | 挺重要。因为人连亏次数太多心态就崩。"30%胜率+5倍盈亏比"那套说法全扯淡——连续五笔全亏，一般人等不到第六笔 |
| 3 | 盈亏比 | 统计每笔交易盈亏比，算平均值。若规则要求每笔必须1:1 / 1.5:1 / 2:1 / 3:1以上，要算实际能不能达到 |
| 4 | 最大回撤 + 连亏次数 | 连续亏了几次、最大回撤多少。**用这个数反推你的仓位和风险偏好**。连亏次数太多或亏损太大，就要调小仓位 |

### 6.3 心态与适配分析：四个维度

回测不只是数字，还要分析你和这套策略合不合：

| # | 维度 | 自查问题 |
|---|------|---------|
| 1 | 时间（持仓时长） | 性格急的人，持仓1~2小时内能接受；这套策略动辄持仓1~2天，你就受不了。若50%~60%的订单都要拿很久，接受不了就有问题 |
| 2 | 感觉 | 回测时看到每根K线跳动，想象它是实盘订单——你会不会提前跑？总会提前跑，说明有问题 |
| 3 | 频率 | 频率特别低（一两天都没有一次做单机会）却想做日内 → 频率有问题。频率高 → 看开仓时间节点能不能对上你的盯盘时间；总在你上班、睡觉、有事的时候才有机会 → 时间节点有问题，需要重新研究 |
| 4 | 风险 | **连亏次数千万控制住**。连亏一多你就崩（有人3次、有人5次，但不管几次都要关注） |

> 关于模拟盘：没用。模拟盘统计300~500笔，黄花菜都凉了。直接做历史回测。

## 七、小资金实盘（迭代验证）

回测和分析都OK之后：

1. 用**能承受的最小资金**上实盘，检验两件事：**执行力**和**适配度**。
   - 回测不是真钱进去，"我OK"都是想象中的OK，O不OK得拿钱去感受。
2. 执行得了 → OK。
3. 执行不了 → 回去更改策略，重新回测。小资金实盘会让你知道问题出在哪：风险偏好、心态、执行力、时间不匹配，还是技术问题（位置找不准、进出场规则不明确）。
4. **不断往复这个循环**：更改条件 → 重新回测 → 分析 → 小资金实盘 → ……直到找到一套适合自己的、能执行的东西，然后心态放平，正常去做。

主讲人自述：这套策略就是这么来的——四个月、一厚摞A4纸、推倒重来多次。

## 八、复盘

很多人忽略，但复盘很重要。四个作用：

| # | 作用 | 说明 |
|---|------|------|
| 1 | 增加数据积累 | 经验源于回测数据 + 实盘数据。数据越多、样本越多，对整体胜率、盈亏比、持仓能力的判断才可信；数据反馈好，才有信心继续做 |
| 2 | 反思当时的心态 | 心态伴随交易一生，只能慢慢克服 |
| 3 | **适当的**优化 | 核心是"适当"，**千万不要过度优化**。反面案例：很多人做EA为了数据好看、为了骗钱，把参数调到过度拟合。正面案例：发现进场后总会给一个回调 → 改成"出现信号后等回调一点再进"，止损更小、止盈更大，盈亏比放大，长期优势更好 |
| 4 | 监控策略是否失效 | 市场在变。**每周复盘**：策略在当前市场是否有效？没问题就继续做；有问题就调整策略 |

---

## 九、结语

- 以上就是搭建完整交易系统的方式，"没有别的办法"。
- 路要自己走。主讲人做了8年，走过这条路，知道哪里有问题——这是他能帮到大家的地方。
- 但每个人都需要自己去做好。
